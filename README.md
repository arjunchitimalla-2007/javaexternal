# Java Practical Programs

A simple, responsive website containing beginner-friendly Java practical programs. Browse by topic, search program names, and copy code with one click.

## Included topics

- Classes and objects
- Default and parameterized constructors
- Constructor and method overloading
- `this`, `super`, `static`, and `final`
- Method overriding and dynamic method dispatch
- String palindrome
- Sorting names in ascending order
- StringTokenizer (integers and sum)
- Checked and unchecked exceptions
- File handling: count characters, words, and lines
- Three threads with different delays
- Producer-consumer using `wait()` and `notify()`
- ArrayList, Vector, Hashtable, and Stack

## Run locally

Open `index.html` in any modern web browser. No installation or build step is required.

## GitHub Pages

To publish it, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
